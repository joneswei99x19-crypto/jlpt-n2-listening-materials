### 1. 题目基本信息

- 年份：2018；月份：7月；级别：N2；栏目：問題1；原始题号：1番。

- 题目：女学生接下来要做什么？
- 听力判断：在展示调查结果的方式上做些改进，例如在表格以外加入图表，让读者一眼看懂。调查和增加对象人数已经完成，分析方法也受到称赞。

### 2. 日语听力原文

```text
1番
大学で男の学生と女の学生が話しています。女の学生はこの後何をしますか。
男：鈴木さん、この間頼まれたレポートのチェックだけど。
女：あ、先輩、もう見てくださったんですか。
男：うん、再調査して対象者の数も増えてよくなったんじゃない。考察も説得力が増して、読んでて面白かったよ。
女：本当ですか、ありがとうございます。再調査、思ったより時間がかかって。でも、やってよかったです。
男：よく頑張ったねえ。うん、せっかくだから、結果の示し方をもう少し工夫してみたら？表ばっかりじゃなくて、少しグラフも入れ
るとか。もう少しパッと見てわかるように。
女：あ、はい。
男：それにしても、この分析方法、面白いね。今度僕も使ってみよう。
女の学生はこの後何をしますか。
```

### 3. 中文翻译（按原文顺序）

男：铃木，之前请我检查的报告……
女：学长，您已经看过了吗？
男：看了。重新调查、增加调查对象人数后，内容不是更好了吗？考察也更有说服力，读起来很有意思。
女：真的吗？谢谢。重新调查比想象中花时间，不过做了真好。
男：你很努力。既然做到这一步，结果呈现方式也再稍微想办法改进一下吧？不要全是表格，也可以加一些图表之类的，让人一眼就能看懂。
女：好的。
男：话说回来，这个分析方法很有意思，下次我也试试。

### 4. 重点词汇与表达

| 日语（基本形） | 假名 | 本句意思 | 等级与来源 |
|---|---|---|---|
| 再調査 | さいちょうさ | 重新调查 | 语境表达 |
| 対象者 | たいしょうしゃ | 调查对象 | 语境表达 |
| 考察 | こうさつ | 考察、分析讨论 | 语境补充；词表无精确匹配 |
| 説得力 | せっとくりょく | 说服力 | N2参考；T03417 |
| 分析方法 | ぶんせきほうほう | 分析方法 | N2参考词条「分析」T04209 |

### 5. 重要语法

1. **结果变化「増えてよくなった」**：再调查并增加样本后，报告质量提高；这是已经完成的工作。
2. **肯定建议「工夫してみたら」**：「てみたら」以委婉方式建议尝试改进。
3. **对比「表ばっかりじゃなくて」**：「ばっかり」是「ばかり」的口语形式，指出报告不应只有表格，还可加图表。
4. **目的「パッと見てわかる」**：希望读者快速扫一眼就能理解，是修改呈现方式的理由。

### 6. 听力理解重点

她接下来的任务不是再做一次调查，而是把结果呈现得更直观；图表是男士给出的具体建议。

### 5. 重要语法

1. **义务「出さなきゃいけない」**：「なきゃいけない」是「なければならない」的口语缩约，表示该寄通知了。
2. **限定对象「郵送物を希望していないお客さんには」**：对于不希望收邮寄物的客户改用邮件，因此不制作地址贴纸。
3. **状态确认「更新されてる」**：「されている」的口语形式，确认会员文件已经更新。
4. **顺序排除**：邮件文案尚未准备好，男士明确说今天不用发；当前先做地址贴纸。

### 6. 听力理解重点

听清“邮寄通知”与“邮件通知”的对象区别：贴纸只给希望收邮寄物的会员制作，邮件正文并未完成。

## 問題1・3番

### 1. 题目基本信息

- 年份：2018；月份：7月；级别：N2；栏目：問題1；原始题号：3番。
- 来源定位：`extracted_text/2018年07月N2听力原文.txt`，原文第 27–42 行。
- 题目：女学生接下来要做什么？
- 听力判断：多准备几件 T 恤。农作服和长靴可以借用，健康检查证明的提交期限已经过了。

### 2. 日语听力原文

```text
3番
大学で女の学生と男の学生が話しています。女の学生はこのあと何をしますか。
女：先輩、去年の夏休みに農業体験行かれたんですよね。大学が主催してる。あれ、私も来週から一ヶ月行くんです。何か持ってった
ほうがいいものとかありますか。
男：ほけんしょう。去年忘れた人がいて大変だったんだよ。コピーすら持ってきてなくて。僕らみたいな素人が農業をやるときは、思
わぬ怪我とかあるから忘れないように気をつけて。
女：はい、いつも持ち歩いています。
男：そう。それから、Tシャツは多めに持ってったほうがいいよ。作業着の中に着るんだけど、作業をしてると想像以上に汗を掻くか
らね。作業着とか長靴は貸してもらえるよ。よく実習生が来るからか、いろんなサイズのがあったよ。
女：よかった。長靴買わなきゃって思ってたけど。Tシャツは、作業着があるからいいかなって思って、部屋着ぐらいしか用意して
ませんでした。
男：そうそう。実は去年、僕、健康診断を受けるのを忘れてて、もう少しで参加できなくなりそうだったんだよ。
女：へえ、で、どうしたんですか。
男：診断書をすぐ出してくれる病院を探して、なんとか間に合ったんだけどね。
女：ああ、それで今年は提出が先週までだったんですね。
女の学生はこのあと何をしますか。
```

### 3. 中文翻译（按原文顺序）

女：学长，去年暑假你参加过大学主办的农业体验吧？我下周也要去一个月。需要带些什么？
男：健康保险证。去年有人忘带，结果很麻烦，连复印件都没带。像我们这样的新手做农业体验，可能会受意外伤，所以别忘了。
女：我平时一直带着。
男：那就好。另外最好多带几件 T 恤。穿在农服里面，干活出汗会比想象中多。农服和长靴可以借，常有实习生来，所以各种尺寸都有。
女：太好了，我还以为得买长靴。我以为有农服就够了，只准备了几件在房间穿的衣服。
男：对了，我去年忘了做健康检查，差点不能参加。
女：后来怎么办？
男：找了一家能马上开诊断书的医院，总算赶上了。
女：啊，所以今年的提交期限提前到上周了。

### 4. 重点词汇与表达

| 日语（基本形） | 假名 | 本句意思 | 等级与来源 |
|---|---|---|---|
| 農業体験 | のうぎょうたいけん | 农业体验 | N3参考成分「農業」T01590、「体験」T01185 |
| 保険証 | ほけんしょう | 医保卡 | 语境补充；词表无精确匹配 |
| 怪我 | けが | 受伤 | 语境补充；词表无精确匹配 |
| 作業着 | さぎょうぎ | 工作服、农服 | 语境补充；词表无精确匹配 |
| 健康診断 | けんこうしんだん | 健康检查 | 语境表达 |

### 5. 重要语法

1. **建议「持ってったほうがいい」**：「持っていったほうがいい」的口语缩约，表示最好带上。
2. **程度超出预期「想像以上に」**：说明劳动时出汗比预想更多，因此需要多带 T 恤。
3. **转折与已提供条件「作業着とか長靴は貸してもらえる」**：工作服和长靴可借，不必购买。
4. **后悔经历与截止时间**：男士去年差点因未做健康检查而无法参加；女生说今年提交截止日期是上周，已来不及作为当前行动。

### 6. 听力理解重点

本题问接下来要做什么。T 恤需多带；长靴可借，健康检查材料也已过提交期限，别把这些干扰信息误作当前任务。

## 問題1・4番

- 听力判断：先向讲师咨询能否用附近买得到的材料替代难以采购的材料；若无法替代，再修改菜单并通知参加者。

### 3. 中文翻译（按原文顺序）

女：是亚洲料理教室吧？菜单已经定了，都是在家也能做的菜。
男：我和讲师商量后拿到了材料清单。原本由我按人数把材料备齐，但有些材料我没听说过，似乎得订购。
女：先问问讲师，能不能用附近买得到的材料代替。如果不容易办到，就要改菜单了。
男：明白。

男：是啊。如果改了菜单，我会通知参加者。

### 4. 重点词汇与表达

| 日语（基本形） | 假名 | 本句意思 | 等级与来源 |

| 代わりに | かわりに | 代替 | N3参考；T00404 |
| 手に入る | てにはいる | 买到、取得 | 固定表达 |

### 5. 重要语法

1. **原因铺垫「聞いたことのない材料があって」**：因为有难以采购的材料，男士说明当前困难。
2. **委婉建议「相談してください」**：课长要求先向讲师商量能否用本地材料替代。
3. **条件「難しいようなら」**：「ようなら」表示如果判断为困难，就修改菜单。
4. **动作顺序**：先咨询讲师，再决定是否改菜单；通知参加者是菜单改变后的步骤。

### 6. 听力理解重点

“先买齐材料”不是课长的安排。先确认能否替代，只有无法找到替代材料时才改菜单并通知参与者。
