1. **先后顺序「終わったら」**：「たら」表示前一动作完成后再做下一件事；这里指发完日程表后设置电脑。

3. **条件必要性「それからじゃないと～ない」**：「否则就不能……」；先重设密码，之后才能操作电脑。

### 5. 重要语法

1. **程度条件「時間がかかるようだと」**：「ようだ」表示情况判断；「～ようだと」提出若达到某种程度就会有后果。
2. **让步「ほかの人にやってもらったほうがいいんだけど」**：「ほうがいい」表示更理想的做法；「んだけど」后接现实限制“日程紧”。
3. **依据「かかった時間によっては」**：「によって」表示根据结果而变化；必要时才更改答题形式。
4. **条件「全員がきちんと回答してくれれば」**：「ば」表示只要所有人认真回答，就足够。

### 3. 中文翻译（按原文顺序）

### 5. 重要语法

1. **目的限制「目的は変えずに」**：「ずに」表示不做前项而做后项；活动形式可以改，员工交流这一目的不变。
2. **让步「予算オーバーになりますが」**：保龄球方案虽能促进团队交流，但超预算，和条件冲突。
3. **对比焦点「社員同士というよりは」**：「というより」表示与其说是员工之间，不如说是员工和居民之间的交流。
4. **决定倾向「思い切ってやることを変えてみよう」**：「てみる」表示尝试；部长倾向选不同于餐厅聚餐的方案。
5. **并列条件「予算内でできて、本来の目的にあっている」**：需同时满足预算与活动目的，烧烤最符合。

### 6. 听力理解重点

原文「おさまりそう」表达烧烤方案预计不超预算；部长最终强调两项筛选条件：预算内、符合员工交流目的。保龄球超支，清扫活动的交流对象偏向社区，常规聚餐则没有改变形式，因此选烧烤。

### 5. 重要语法

1. **理由「生け花が趣味だから」**：花瓶与部长的插花爱好直接相关。
2. **让步「喜んでもらえそうだけど」**：花瓶可能受欢迎，但价格是顾虑。
3. **限制条件「好みに合ったものじゃないと」**：「ないと」在此表示如果不符合喜好就不行，因此围巾和餐具难以选择。
4. **共同承担「3人で出し合えば」**：「ば」表示三人共同出钱这一条件成立，就能买到更好的礼物。
5. **目的「趣味に使ってもらえるもの」**：最终筛选标准是能用于爱好、可长期使用。

### 6. 听力理解重点

### 5. 重要语法

1. **比较「一緒に写真を撮れるのなんて」**：「なんて」举出一种选择，女方认为合影适合作礼物；男士随后用父亲不喜欢拍照排除。
